| `app.hello` | `deviceId`, `app.version` | `Id`, `Type.String()` (required) | No | Keep required; device handshake cannot omit identity or app version. |
| `app.hello` | `subscriptions` | `Type.Optional(Type.Literal("all"))` | Yes | Already optional. |
| `agent.subscribe` | `agentId` | `Id` (required) | No | Keep required; cannot subscribe without agent identifier. |
| `agent.subscribe` | `sinceSeq`, `epoch` | `OptNullable(...)` | Yes | Already `OptNullable` (absent / null / value supported). |
| `agent.unsubscribe` | `agentId` | `Id` (required) | No | Keep required; unsubscribe target must be explicit. |
| `user.message` | `clientMsgId`, `agentId`, `text` | `Id`, `Id`, `Type.String()` (required) | No | Keep required; core message semantics. |
| `user.message` | `deviceId`, `attachments`, `delivery`, `method`, `asCommand` | `Type.Optional(...)` | Yes | Already optional. |
| `agent.abort` | `agentId` | `Id` (required) | No | Keep required; abort target must be explicit. |
| `prompt.answer` | `promptId`, `answer` | `Id`, `Answer` (required) | No | Keep required; answering requires prompt ID and valid answer union. |
| `agent.forget` | `agentId` | `Id` (required) | No | Keep required; forget target must be explicit. |
| `push.ack` | `pushId` | `Id` (required) | No | Keep required; acking push requires push ID. |
| `host.list_dirs` | `machineId`, `path` | `Id`, `Type.String()` (required) | No | Keep required; host filesystem operations require machine and path. |
